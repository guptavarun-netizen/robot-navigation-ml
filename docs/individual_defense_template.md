## Defense prompts

1. State the project question and define one row/observation in each dataset.
2. Explain why macro-F1 is reported alongside accuracy, and describe the
   baseline result.
3. Explain what was fitted using training data only and how the held-out data
   was kept out of model selection.
4. Describe one error or failure mode in the results and one limitation that
   changes how the conclusion should be read.
5. For the BARN evaluation, explain why splitting by map ID is stronger than
   randomly splitting path steps, and why it still is not a physical robot
   test.
6. Describe the TurtleBot3 dropout replay and distinguish masking saved scan
   values from physically disconnecting or degrading a sensor.
7. Identify one modeling or preprocessing decision you made and predict how a
   small change to it would affect the results.
